# EMDR

Пересобранная версия проекта [emdr](https://github.com/Koshelenok/emdr) на стеке **React.js**, **TypeScript** и **Tailwind CSS**. Проект собран с помощью ИИ-агента.

## Зачем этот шарик

В EMDR-терапии используются движения глаз из стороны в сторону. Шарик показывает это в простом виде: он плавно двигается по экрану влево-вправо, а человек следит за ним глазами.

**Оригинальный репозиторий:** https://github.com/Koshelenok/emdr

> Демонстрационный проект. Не медицинское изделие и не замена работе со специалистом.
